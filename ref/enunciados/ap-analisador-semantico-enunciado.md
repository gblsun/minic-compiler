# AP 2 - Analisador Semântico

Seguem os testes e scripts de automação para validação do analisador semântico do compilador MINIC. 
Os códigos referentes aos parsers devem ser chamados com os seguintes comandos:

### Python:
```bash
./testes_semanticos_py.sh minic.py [diretorio]
```

### C:
```bash
./testes_semanticos_c.sh minic.c [diretorio]
```
